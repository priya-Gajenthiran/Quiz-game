## Overview
This is a simple **console-based quiz game** built in Java.  
The program asks multiple-choice questions, takes user input, checks if the answer is correct, and displays the score at the end.  

This project demonstrates my knowledge of **Core Java**, including:
- Input handling using the Scanner class
- Conditional statements
- Looping constructs
- Basic object-oriented programming concepts

---

## Features ✨
- Multiple-choice question-based quiz
- Instant feedback (Correct / Incorrect)
- Score calculation at the end of the quiz
- Easy to extend with more questions
